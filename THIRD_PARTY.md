# Third-party components

This repository builds on and includes source code derived from:

- **Casanovo** (https://github.com/Noble-Lab/casanovo) — transformer de novo
  peptide sequencing backbone and data preprocessing utilities. Please follow
  the upstream license.
- **Depthcharge** (https://github.com/wenb1106/depthcharge) — spectrum
  encoder components imported by the Casanovo backbone code.

Model checkpoints distributed with this repository were trained on
search-engine-produced peptide-spectrum matches (see README for provenance);
they are pseudolabels rather than manually validated ground truth.
